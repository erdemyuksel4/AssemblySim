## Page 1

COURSE INFORMATION
COURSE CODE: BMI3121
COURSE NAME: Microprocessors
FACULTY / DEPARTMENT: Faculty of Engineering and Natural Sciences – Department of
Computer Engineering
16-Week Course Plan
Week 1: Introduction to microprocessors, role in computer systems, number systems, data
representation
Week 2: Microprocessor architecture, registers, flags, memory addressing, segment:offset concept
Week 3: Addressing modes, data addressing, program control addressing, stack organization and
operations
Week 4: Data transfer instructions, MOV, LEA, STOS, MOVS, XCHG, IN and OUT
Week 5: Arithmetic and logic instructions, addition, subtraction, multiplication, division, logical
operations, shifts and rotates
Week 6: Program control instructions, unconditional and conditional jumps, loops, procedure calls,
interrupts
Week 7: Input and output systems, programmed I/O, interrupt-driven I/O, direct memory access
(DMA)
Week 8: Midterm Examination
Week 9: Operating system support, process management, scheduling, process states, Process
Control Block (PCB)
Week 10: Instruction sets: structure and functions, opcodes, operands, symbolic representation,
instruction types
Week 11: Instruction addressing modes and formats, immediate, direct, indirect, register,
displacement, relative, base, indexed
Week 12: Processor structure and function, ALU, control unit, registers, instruction cycle, instruction
pipelining
Week 13: Assembly language programming, writing and running programs, macros, reusability,
conditional macros
Week 14: Assembly programming of Intel 8085, programming model, instruction set, addressing
modes, sample programs
Week 15: Advanced topics, pipeline performance and hazards, RISC vs CISC, microprocessor
applications
Week 16: Final Examination
